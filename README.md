# Цифровая муха: симуляция мозга мухи, смотрящего видео

Симуляция на C++ **полного оцифрованного коннектома ЦНС мухи** (FlyWire/Princeton):
**166 700 нейронов, 6 242 118 уникальных связей, 89 860 280 синапсов** — реальные
данные электронной микроскопии, а не абстрактная сеть. Муха «смотрит» видео с
YouTube (или локальный файл), изображение подаётся на фоторецепторы и ламину, сигнал
распространяется **по настоящей проводке**, и с выходов считываются метрики:
количество попыток побега, график удовлетворённости, классификация поведения.

## Как скачать данные и собрать

Данные коннектома в репозиторий не входят. Нужны два файла из публичного
релиза FlyWire/Princeton (v783, снимок октября 2023):

- `neurons.csv` — метаданные нейронов;
- `connections_princeton.csv` — связи (pre, post, neuropil, syn_count).

Скачайте экспорт через [FlyWire Codex](https://codex.flywire.ai/) / портал
FlyWire и положите файлы в `..\neyron\` рядом с проектом (или укажите
`--dir <папка>`). Кэш `connectome.bin` создаётся при первом `validate` в рабочей
папке.

Лицензия данных — **CC BY-NC 4.0** (только некоммерческое использование, с
атрибуцией): [flywire.ai/guidelines](https://flywire.ai/guidelines). Цитируйте
Dorkenwald et al., *Nature* 634, 124–138 (2024),
[doi:10.1038/s41586-024-07558-y](https://doi.org/10.1038/s41586-024-07558-y),
и FlyWire Consortium; аннотации — Schlegel et al., *Nature* 634, 139–152 (2024),
[doi:10.1038/s41586-024-07686-5](https://doi.org/10.1038/s41586-024-07686-5).

Сборка: `build.bat` (native) или `build.bat portable`; проверка: `check.bat`
(требует локальные видео и эталон, см. «Проверка»). Репозиторий не содержит
данных, видео, exe и кэша.

## Зависимости

- Windows 10/11 x64 (Winsock, winmm).
- MinGW-W64 g++ 16.2.0 (UCRT/POSIX/SEH), ffmpeg N-127957, yt-dlp 2026.10.21 —
  портативные в `..\tools\` (в репозиторий не входят).
- Для YouTube нужен интернет; без JS-рантайма yt-dlp доступен ограниченный
  набор форматов (480p достаточно для глаза 320×180).

## Ограничения

- Только Windows: HTTP-сервер на Winsock, таймеры winmm.
- Данные коннектома и видео не входят в репозиторий; без них доступны только
  сборка и `validate` после скачивания CSV.
- «Удовлетворённость» и «поведение» — прокси-индексы, не измерение эмоций.

## Быстрый старт

Сборка по умолчанию — под этот CPU (`-march=native`), как в золотой линии.
`build.bat portable` — переносимая сборка без native: 20-с CSV и скорость те же,
но на 400-с прогоне возможно расхождение в последнем печатном знаке (накопленное
различие codegen, не модели). Инструменты (портативные, уже в `..\tools\`):
g++ 16.2.0 (WinLibs), ffmpeg, yt-dlp.
Поиск: `..\tools\`, `tools\`, `PATH`, либо `FLYSIM_FFMPEG` / `FLYSIM_YTDLP`.
Данные: `..\neyron\neurons.csv`, `..\neyron\connections_princeton.csv`
(или `--dir <папка>`); кэш `connectome.bin` — в рабочей папке (`--cache <файл>`).

```bat
build.bat                                   :: сборка flysim.exe (~40 c, -march=native)
build.bat portable                          :: переносимая flysim_portable.exe (без native)
check.bat                                   :: регрессия: validate/eyetest/shuffle/CSV/скорость
flysim.exe validate                         :: проверка коннектома, создание кэша connectome.bin

:: главное: муха смотрит YouTube (вставьте свою ссылку)
flysim.exe run --url "https://www.youtube.com/watch?v=XXXXXXXXXXX" --max-sec 120

:: LIVE-режим: браузер открывается сам — видео, статистика, карта 166 700 нейронов
flysim.exe --live run --url "https://www.youtube.com/watch?v=XXXXXXXXXXX"
flysim.exe --live run --video clip.mp4 --speed max

:: повтор записанной сессии (без пересчёта; play/seek в браузере ведёт данные)
flysim.exe replay out\metrics_run.csv --video out\ytvideo.mp4

:: контроль на перемешанной проводке / тесты / перегенерация отчёта из CSV
flysim.exe --shuffle run --url "..." --max-sec 120
flysim.exe selftest
flysim.exe eyetest
flysim.exe report [--video out\metrics_run.csv] [--escape-refractory S]
```

Опции: `--max-sec N`, `--threads N` (результат не зависит от числа потоков),
`--seed N` (реализация шума), `--escape-refractory S` (дефолт 1.5 с, применяется
и в `report`), `--shuffle [--seed N]`, `--rebuild`, `--dir <папка>` (данные,
дефолт `..\neyron`), `--cache <файл>` (кэш, дефолт `connectome.bin`). Live: `--live [--port N]`
(дефолт 8765, при занятости авто-переключение на +1..+9), `--realtime` /
`--speed 0.5|1|2|max` (в live по умолчанию 1.0×). Прогон без `--live` полностью
идентичен по CSV (проверено байт-в-байт) — сервер живёт в отдельных потоках,
симуляция никогда на него не ждёт (publish через try_lock, кадры отбрасываются,
а не блокируются).

### Live-режим (`--live`)

Встроенный HTTP-сервер **только на 127.0.0.1** (Winsock, без внешних библиотек,
страница вшита в exe, никаких CDN). Эндпоинты: `/` (страница), `/stats` (JSON,
~20 Гц), `/frame.bin` (активность всех 166 700 нейронов, байт/нейрон),
`/eye.bin` (сетка глаза 768×3), `/layout.bin` (карта+метаданные), `/groups`,
`/pipeline` (веса синапсов между узлами пути), `/video` (ролик с HTTP Range),
`POST /ctl` (управление). Страница: видео, синхронизированное с часами
симуляции (при отставании расчёта видео подстраивается под него), сетка
омматидиев поверх видео и превью «что видит муха»; карточки (побеги,
поведение, скорость, время, кадр, активные нейроны, потоки); скользящие
графики за 60 с (DNp01+LC4 с пунктирами побегов, удовлетворённость,
глазные признаки); журнал побегов со вспышкой и опциональным звуком; карта
активности нейронов (пиксель = нейрон, группировка по классам, ховер: root ID,
тип, класс, нейромедиатор; карта схематична — 3D-координат в данных нет);
схема пути фоторецепторы→ламина→T4/T5→LC4/LPLC2→DNp01→моторные с подсветкой
активности; топ-20 активных нейронов (root ID, тип, класс, активность).
Управление со страницы: пауза, скорость, перезапуск, «лезия» (выключение
группы: LC4/LPLC2, T4/T5, дофаминовые, фоторецепторы, MBON — помечается
баннером и колонкой lesion в CSV; это нарушает чистоту эксперимента), вставка
новой ссылки YouTube без перезапуска. Закрытие браузера не влияет на расчёт;
повторное открытие подхватывает текущее состояние. После live-прогона
сохраняются те же CSV и HTML-отчёт, что и без него.

`flysim replay metrics.csv --video файл` — тот же интерфейс в режиме
просмотра: play/seek видео ведут данные из готового CSV; карта нейронов
показывает агрегаты по классам (по-нейронной активности в CSV нет — указано
на странице).

Прочее: дашборд-отчёт `out/report.html` содержит таблицу событий побега,
встроенный самотест «карточка = таблица = пунктиры» (красный баннер при
рассинхроне; в live-странице тот же тест) и пометки об ограничениях. Пути с
пробелами и кириллицей поддерживаются (8.3-короткие имена). Запускайте из
корня проекта (выход — относительный `out\`).

### Замеры (аудит live)

- Скорость: 1.0–1.3× реального времени в зависимости от CPU и нагрузки
  (аудит 2026-11-26: 1.05–1.16× на 20-с прогоне); live-макс заметно не замедлял.
  При темпинге 1.0× фактическая ниже из-за гранулярности sleep Windows —
  честно показывается на карточке скорости.
- Память: стабильно 117 МБ в ходе live-прогона (утечек нет); аудит 2026-11-26:
  112.6 МБ рабочего множества, пик загрузчика 337 МБ.
- Идентичность: CSV с live и без, при 16 и 4 потоках — байт-в-байт (один seed).
- Аудит 2026-11-26: 20 с — 1.24× (16 потоков), 400 с — 1.2×; 400-с CSV native
  байт-в-байт; live + 5 пауз — CSV байт-в-байт.
- Известное происшествие: одно зависание в первой тестовой сессии при
  последовательном закрытии вкладок; первопричина — цикл «симуляция ждёт
  мьютекс → перестаёт читать пайп → ffmpeg замирает»; после перевода publish
  на try_lock (симуляция никогда не ждёт сервер) точная последовательность
  воспроизведена дважды без зависаний.

**Выход** (после `run`):
- `out/report.html` — дашборд: KPI, DNp01+LC4 с отметками побегов, график
  удовлетворённости, полоса поведения, активность популяций, глазной вход;
- `out/metrics_run.csv` — все временные ряды (24 колонки, 30 Гц; последняя — `lesion`);
- `out/ytvideo.mp4` — скачанное видео;
- консольная сводка: длительность, попытки побега с таймкодами, min/max
  удовлетворённости, распределение поведения, скорость.

Первый `validate` парсит CSV (на этом ПК ~1.5 с) и создаёт кэш `connectome.bin`
(79.4 МБ); дальше загрузка за секунды. Симуляция идёт на 16 потоках со скоростью
~1.0–1.2× реального времени на этом ПК. Регрессия: `check.bat` (~1.5 мин) сверяет
validate/eyetest/shuffle, CSV 20 с (seed 42, 16 и 4 потока) с `out\baseline\` и

## Модель динамики (выбрана rate-модель)

### Rate-модель (используется)

Лейкинтегратор для нормированной скорости стрельбы `r_i ∈ [0,1]`:

```
I_i(t)   = Σ_{j→i} s(nt_j) · w_ji · (r_j − ref_rate) / (Σ_{j→i} w_ji)
r_i(t+dt)= λ·r_i(t) + (1−λ)·clamp01( gain·(I_i + ext_i) + bias )
λ = exp(−dt/τ),  dt = 5 мс, τ = 50 мс
```

- `w_ji` — суммарное число синапсов пары (j,i) (связи схлопнуты по нейропилям);
- `s(nt)` — знак по нейромедиатору пресинаптического нейрона:
  ACh/Glu = +1, **GABA/Hist = −1** (гистамин фоторецепторов открывает Cl-каналы
  ламины — поэтому ламина активна в темноте), DA/Oct/5-HT = +0.3 (медленные
  модуляторы), unknown = +0.5;
- `ref_rate = 0.05` — центрирование: в покое I≈0, активность держится около
  bias=0.02, распространяются только **отклонения**. Без этого сеть насыщается:
  большинство синапсов возбуждающие, Σ sign·w·r/Σw ≈ +0.5·r;
- `gain = 1.2` — петлевое усиление gain·S < 1 (S≈0.7 — знаковое сальдо весов),
  выше — сеть уходит в насыщение (проверено эмпирически: gain=4 → 46% нейронов
  прижаты к 1.0);
- шум ±0.01 на входе (детерминированный хэш).

### LIF (Shiu et al. 2024, Nature) — реализована, сравнена, не выбрана

Воспроизведена по первоисточнику (Shiu, P.K. et al. «A Drosophila computational
brain model reveals whole-brain spontaneous activity and stimulus-induced
switching», Nature 635, 2024; код github.com/philshiu/Drosophila_brain_model):

```
dv/dt = (v0 − v + g)/τ_m ;  dg/dt = −g/τ_syn ;  спайк при v > v_th, сброс v и g
v0 = −52 мВ, v_th = −45 мВ, τ_m = 20 мс, τ_syn = 5 мс, t_ref = 2.2 мс,
w = 0.275 мВ × число синапсов (БЕЗ нормировки), фон: Пуассон
```
Синаптическая задержка 1.8 мс у Shiu не моделируется (меньше шага 5 мс). Фоновый
шум снижен со 150 Гц×2 мВ до 30 Гц×1 мВ: их уровень держал весь ЦНС
(с ножными петлями, которых у них не было) на пороге.

### Почему rate

| Критерий | rate | LIF (Shiu) |
|---|---|---|
| Покой | 0.007, прижатых 0% | тишина (0.000) |
| Отклик на стимул | градуированный, **полностью обратимый** | лавина с гистерезисом: GF 0.95, MBON 0.87, после стимула не возвращается |
| Скорость | **1.2× реального времени** | 0.9× |
| Чувствительность чтения | GF ×19 к покою на лунинге | всё в насыщении |

LIF без нормировки весов на полном ЦНС (мозг+VNC, с восходящими петлями)
бистабилен — «переключение состояний» в вырожденной форме. Для непрерывного
видео и временных метрик нужен обратимый градуированный режим → rate.
Нормализованный LIF остаётся запасным вариантом (зафиксировано как
отклонение от Shiu 2024).

## Мушиный глаз (чистый режим, правка 3)

Внешнее воздействие — **только** на фоторецепторы (жёсткий кламп скорости) и
ламину (аддитивный вход). Всё остальное — работа реальной проводки.

Кадр 320×180 сэмплируется сеткой 768 «омматидиев» (32×24, ~как один глаз мухи;
экран — фронтальное бинокулярное поле). На позицию p:

- адаптированный контраст `c = L − L_adapt` (фоторецепторная адаптация, τ=3.5 c);
- транзиент `d = |L(t) − L(t−1)|`;
- движение `m` — EMD Хассенштейна-Райхардта (полукоррелятор с задержкой 1 кадр,
  горизонталь+вертикаль);

```
фоторецепторы:  r = clamp01(0.08 + 0.55·max(0,c) + 0.5·d + 0.35·m)   [посветление → гистамин → торможение ламины]
ламина (ext):   e = 0.9·max(0,−c) + 0.9·m + 0.7·d                    [потемнение → активация ламины]
```

Полярность соответствует реальной цепи: фоторецептор деполяризуется на свет,
гистамин **тормозит** LMC, ламина активна в темноте — тёмный надвигающийся
объект согласованно активирует ламину обоими каналами. Ретинотопия —
детерминированное хэш-распределение реальных клеток по позициям (морфологии в
экспорте нет; типы и количества реальны, точная топография — нет).
Режим `eyetest lc` — прямая подача на LC4/LPLC2 для отладки тракта считывания.

## Метрики

- **Попытка побега** — всплеск гигантского волокна DNp01 (root ID 10001/10010,
  проверено по Primary Cell Type/Class/Sub Class): средняя скорость двух GF-нейронов
  выше `max(0.025, базлайн+3σ)` (EMA τ=10 c — привыкание), рефрактерность 0.7 с.
  Регистрируются таймкод, уровень GF и LC4.
- **Удовлетворённость** (прокси, правка 7): z-оценки (EMA τ=10 c, floor σ=0.0015)
  реальных нейромодуляторных популяций:
  `S = 0.5 + 0.5·tanh(1.5·(z_DA + 0.6·z_MBON − 0.6·z_OCT − 0.3·z_SER))` ∈ [0,1].
  Дофамин (награда) и выходы грибовидных тел в плюс, октопамин (стресс/возбуждение)
  и серотонин в минус. Это не измерение эмоций, а индекс внутреннего состояния
  по биологически обоснованным популяциям.
- **Поведение** (каждый кадр): ESCAPE (окно 0.5 c после всплеска GF) → FLIGHT
  (DN→тектулум, 721 нейрон) → WALK/GROOM (DN→LegNp, 568) → ACTIVE (все DN,
  1314) → REST. Пороги = базлайн (EMA τ=20 c) + max(4σ, 0.35·базлайн).
  Это «намерения» мухи (команды нисходящих нейронов), не физика мышц.

## Валидация

1. **Проводка сходится с биологией**: топ-входы гигантского волокна — LC4
   (6362 син., 126 клеток) и LPLC2 (4836) — реальные детекторы лунинга;
   путь фото→GF по связям — 3–4 синапса (обратный BFS).
2. **Лунинг работает в чистом режиме**: чёрный диск с ускоряющимся приближением —
   GF растёт монотонно и пикует у «столкновения» (пик 0.056 = ×19 к покою),
   LC4 ×40. Мерцание тоже стартлит (правдоподобно), отступление и движущаяся
   решётка — побега не дают.
3. **Контроль на перемешанной проводке** (правка 4): те же степени, NT-знаки,
   группы и вход; случайна только проводка (3 сида) — GF на лунинге 0.018–0.023
   (×3 слабее), LC4 ×5 слабее, **попыток побега 0 против 2**. Ламина отвечает
   одинаково (драйвится напрямую) — различие возникает ниже по потоку.
   **Вывод: лунинг-ответ и побеги производит проводка мухи**, а не модель входа
   или модель считывания.

## Честные допущения и ограничения

- Коннектом — это «проводка» без физиологии: временные параметры задаёт модель.
  Стандартный компромисс всех симуляций коннектомов; структура связей полностью
  реальна.
- Rate-модель линейно-пороговая: воспроизводит распространение и усиление
  активности, но не спайковые коды и точные времена (LIF для этого есть, но
  бистабилен на этом графе — см. выше).
- Ретинотопия приближённая (хэш), EMD вынесен во входной каскад —
  направленная селективность T4/T5 не воспроизводится эмерджентно.
- Видео 30 fps — в 10 раз медленнее зрения мухи; быструю фликер-чувствительность
  муха «не видит». Звук (орган Джонстона) не подаётся — путь для будущего этапа.
- «Удовлетворённость» и «поведение» — прокси-индексы по реальным популяциям,
  калиброванные на синтетике; на реальном видео интерпретируйте как
  «валентность внутреннего состояния» и «моторные намерения».
- Один мозг = одна муха (детерминизм по сиду); популяционной статистики нет.

### Технические ограничения (аудит 2026-10-24)

- yt-dlp без установленного JS-рантайма (deno/node) получает ограниченный список
  форматов и медленную скорость YouTube (~200–600 КиБ/с); программа качает 480p
  (глазу хватает 320×180) с параллельными фрагментами (`-N 8`). Полный
  30-минутный ролик скачивается минуты 2–5. Битые ссылки, недоступные и
  age-restricted видео обрабатываются корректной ошибкой (age-restricted
  отдельно не тестировались — путь тот же: код возврата yt-dlp).
- Видео короче 2 с: индекс удовлетворённости не выходит из 0.5 (прогрев сети);
  побеги возможны, но статистики нет.
- Принудительное закрытие программы не оставляет процессов-сирот (ffmpeg
  завершается по обрыву пайпа; проверено).
- Дашборд и CSV полностью офлайн (CDN не используются); числа в CSV и на
  графиках — из одного файла данных.
- Резервная копия кода: `..\project-fly-neyrons_backup_v3` (вне репозитория,
  без больших CSV).
