# Design

## Контекст

- Windows 10 22H2, Windows PowerShell 5.1, MinGW-W64 g++ 16.2.0.
- Данные: `neyron\neurons.csv`, `neyron\connections_princeton.csv` (копии в
  корне проекта идентичны по SHA256).
- Кэш: `connectome.bin` (79 355 991 байт), загрузка из кэша.
- Научная часть заморожена: dt=5 мс, τ=50 мс, gain=1.2, bias=0.02,
  ref_rate=0.05, знаки NT, формулы глаза и метрик.

## Золотая линия

| Проверка | Эталон |
|---|---|
| `validate` | 166 700 / 9 039 608 / 6 242 118 / 89 860 280 |
| `eyetest` | 2 побега (лунинг, мерцание), покой/отступление/решётка 0 |
| пик GF на лунинге | ≈0.056 (×19 к покою), LC4 ×40 |
| `--shuffle eyetest` | 0 побегов, GF ≈0.018–0.023 |
| CSV `--seed 42`, локальное видео 20 с и 400 с | байт-в-байт эталон |
| live / без live, 16 / 4 потока, паузы | байт-в-байт |
| скорость | ≈1.30× без live; накладные с live <2% |
| память | ≈117 МБ в работе; пик загрузчика ≈329 МБ |
| сборка | 0 предупреждений `-Wall -Wextra` |

## Стратегия проверки

1. `check.bat` (PowerShell 5.1) за 1–2 минуты: validate, eyetest, eyetest lc,
   -shuffle eyetest, короткий прогон seed 42 со сверкой SHA256, threads 16/4,
   замер скорости.
2. Для багфиксов и очистки — байт-в-байт обязателен; при расхождении откат и
   запись в журнал.
3. Для оптимизации допуск предлагается владельцу до правок; по умолчанию
   сравнение с эталоном и явный отчёт о любом расхождении.
4. Долгие прогоны — только в фоне (`Start-Process` + лог).

## Пути и переносимость

- Корень проекта: `%~dp0`; тулчейн: `..\tools\mingw64\bin\g++.exe`.
- Данные: аргумент/переменная, по умолчанию `..\neyron\`; если файла нет —
  искать в корне проекта (обратная совместимость).
- ffmpeg: `..\tools\ffmpeg-*\bin\ffmpeg.exe` или `PATH`; yt-dlp: `..\tools\`
  или `PATH`.
- `-march=native` вынести в отдельную цель/опцию, базовая сборка — переносимая.

## Порядок и откат

- Одно изменение за шаг; после каждого — сборка и `check.bat`.
- Перед правкой — копия файла в `out\audit_backup\` (или git-патч), чтобы откат
  был точным.
- Любая побочная находка сразу в бэклог `openspec\...\journal.md`, текущий шаг
  не бросается.
