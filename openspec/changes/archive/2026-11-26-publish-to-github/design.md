# Design

## Принципы

- Сначала private; public — только по отдельной команде владельца.
- Три явных подтверждения: создание репозитория, первый push, смена видимости.
- Без Git LFS и без файлов >50 МБ.
- Секреты и токены не попадают в файлы, логи и историю.
- Код и научные результаты не меняются.

## Исключения

`*.exe`, `*.o`, `*.obj`, `*.bin`, `*.log`, `*.csv` (в корне и везде), `out/`,
`tools/`, `project-fly-neyrons_backup_v3/`, `graphify-out/cache/`, `*.tmp`,
`*.zip`, `.vscode/`, `Thumbs.db`. `openspec/` — по решению владельца.

## Проверки

1. `git status --short --ignored` — что реально попадёт.
2. Размеры трекаемых файлов: максимум <50 МБ.
3. `Select-String` по `password|token|secret|api_key` и личным путям
   (профиль пользователя, рабочая папка) в трекаемых файлах.
4. Личные пути заменяются только в `*.md`; код не трогаем.
5. После push — клон во `%TEMP%`, проверка структуры и отсутствия данных.

## История

2–3 коммита: код; документы; скрипты проверки/конфигурация. Сообщения на
английском, без тегов.

## GitHub

`gh auth login` выполняет владелец. Репозиторий создаётся
`gh repo create <name> --private --source=. --remote=origin` без push; push — после
подтверждения. Описание и topics задаются после создания.
